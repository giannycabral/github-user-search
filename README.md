# GitHub User Search 🔍🌸

Uma aplicação web kawaii e interativa para buscar perfis de usuários do GitHub. Desenvolvida com um design fofo em tons de lilás e rosa, apresenta animações suaves, interações divertidas e um mascote Octocat animado.

https://github.com/user-attachments/assets/a5244076-cc5c-495d-88fd-a6fb5d27dca1

## ✨ Funcionalidades

- 🔎 Pesquisa de usuários do GitHub com feedback visual
- 👤 Visualização detalhada e estilizada do perfil
- 🖼️ Avatar do usuário em formato circular com bordas decorativas
- 📊 Estatísticas animadas de repositórios, seguidores e seguindo
- 🌓 Design kawaii com alternância de tema claro/escuro
- 🎨 Interface com cores suaves em tons de lilás e rosa
- 🐱 Octocat interativo com animações e mensagens
- 📱 Layout totalmente responsivo para todos os dispositivos
- 🔗 Botão estilizado para visitar o perfil do GitHub
- 📤 Opção de compartilhamento do perfil
- 💬 Balões de fala interativos no mascote

## 🎨 Design e Interface

- Tema kawaii com tons de lilás, rosa e elementos decorativos
- Cantos arredondados e bordas suaves
- Animações interativas em elementos chave
- Octocat com múltiplas animações (pulando, andando, acenando)
- Efeitos de glassmorphism e sombras suaves
- Ícones temáticos e decorações estilizadas
- Botão de tema com animação pulsante e tooltip informativo
- Mensagem de boas-vindas com instruções para usuários

## 🛠️ Tecnologias Utilizadas

- HTML5 Semântico
- CSS3
  - Variáveis CSS para temas claro/escuro
  - Animações complexas e transições
  - Flexbox para layout responsivo
  - Media queries detalhadas para todos os dispositivos
  - Efeitos de glassmorphism e gradientes
- JavaScript (ES6+)
  - Fetch API para requisições à API do GitHub
  - LocalStorage para persistência do tema
  - DOM Manipulation para interações dinâmicas
  - Animações controladas por JavaScript
- GitHub REST API v3
- Font Awesome Icons 6.0

## 🚀 Instalação

1. Clone o repositório:
```bash
git clone https://github.com/giannycabral/github-user-search.git
```

2. Navegue até o diretório do projeto:
```bash
cd github-user-search
```

3. Instale as dependências:
```bash
npm install
```

4. Inicie o servidor de desenvolvimento:
```bash
npm start
```

5. Acesse `http://localhost:8080` no seu navegador

## 🎮 Como Usar

1. Ao abrir a aplicação, você verá uma tela de boas-vindas com instruções
2. Digite o nome de usuário do GitHub na barra de pesquisa
3. Clique em "Pesquisar" ou pressione Enter
4. Visualize as informações do perfil com animações:
   - Foto do perfil com efeitos
   - Nome completo e username
   - Biografia do usuário
   - Estatísticas com contadores animados
   - Botões para acessar o perfil ou compartilhar
5. Interaja com o Octocat passando o mouse sobre ele
6. Alterne entre os temas claro e escuro usando o botão no canto superior esquerdo
